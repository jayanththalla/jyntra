# ATS providers

Generated by `npx tsx scripts/gen-provider-docs.ts` from `lib/ingestion/providers/index.ts` (single source of truth).

`Verification` states what has actually been run. "Fixture" means parsing is tested against hand-written payloads in the documented shape, **not** a recording of a live response.

## Greenhouse (`greenhouse`)

- **Endpoint:** `GET https://boards-api.greenhouse.io/v1/boards/{token}/jobs?content=true`
- **Vendor-documented API:** yes
- **Authentication:** none (Job Board API is public)
- **Resolving the board:** token = path segment of boards.greenhouse.io/{token} or job-boards.greenhouse.io/{token}
- **Fields used:** id, title, absolute_url, location.name, offices, departments, content (HTML), first_published when present
- **Pagination:** none: one response with every job (meta.total checked)
- **Rate limits:** undocumented; 429 + Retry-After honoured
- **Limitations:** updated_at is the last edit, never used as posted date. Payload can be several MB on big boards (40 MB cap).
- **Verification:** Parsing covered by fixture tests (scripts/test-ingestion.ts). Live endpoint NOT run from the build sandbox (outbound ATS hosts unreachable); run `npm run jobs:validate-live`.
